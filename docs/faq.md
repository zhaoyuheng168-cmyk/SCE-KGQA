# FAQ

## Is this the full research repository?

No. This is a clean showcase containing a small runnable graph, selected V8
source files, formal result summaries and public documentation. The original
research repository remains separate.

## Can this repository reproduce 88.23% and 92.23%?

No. The lightweight demo does not contain the complete graph, evidence corpus,
1300-question test set, Gold answers, indexes or frozen server environment.
The figures are copied from the frozen formal result table and are not
recomputed here.

## Why is the complete Gold file absent?

The paper is submitted and has not been accepted. The complete formal Gold is
kept outside this public-oriented repository to avoid benchmark leakage and to
respect publication timing.

## Why are there two Full System values in the research materials?

The main comparison and ablation experiment were produced by different frozen
outputs. Their strict-accuracy counts differ by one of 1300 questions. The
main result is reported as 88.23%, while the ablation Full System is 88.31%.
Each value is compared only within its own experiment group; the two Full
System values are not mixed across tables.

## Does `servesEnterprise` prove that financing occurred?

Not necessarily. The sample marks those edges as `expanded`: they map product
target groups to compatible enterprise features. A confirmed financing event
requires a dedicated event node and supporting evidence.

## Is the paper published?

No. It has been submitted and has not been accepted or published.
