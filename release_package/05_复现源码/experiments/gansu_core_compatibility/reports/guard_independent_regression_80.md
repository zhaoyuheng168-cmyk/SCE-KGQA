# Core Route Guard 独立 80 题回归报告

实验日期：2026-06-10  
协议：`gansu_core_route_guard_independent_regression_v1`  
来源：既有正式 1300 题 V8 结果与 task-aware gold  
独立性：与冻结 16 题开发/消融集的问题文本重叠为 0

## 1. 回归集构成

从既有正式 1300 题结果中确定性分层抽取 80 题：

- 40 道 Guard 可识别唯一 Core 公共路径的问题；
- 40 道 Core 当前未覆盖、应当旁路的问题。

公共路径样本构成：

| 路径 | 数量 |
|---|---:|
| `institution_products` | 13 |
| `product_provider` | 12 |
| `policy_products` | 12 |
| `policy_region_overview` | 3 |

另外 40 道旁路题覆盖规则推理、企业关系、多跳产品路径、贷款/补贴事件、拒答等多种 V8 扩展能力。

## 4. 为什么没有纠正独立集中的原始错误

独立集中的原始错误主要不是目标类型冲突。

例如，某些 `product_provider` 问题的 V8 答案节点类型确实是 `FinancialInstitution`，只是与正式 gold 存在实体名称规范化、别名、漏答或多答差异。当前 Route Guard 的职责是阻止以下问题：

```text
问题要求 FinancialProduct，系统却返回 Enterprise；
问题要求 Region，系统却返回 Enterprise；
存在唯一合法 Core 路径，但系统为空答案。
```

它不会在答案类型已经正确时，使用 gold 或 Core 路径强行覆盖 V8。因此本轮保持原答案是符合设计预期的保守行为。

## 5. 与冻结 16 题消融的联合结论

| 实验 | 样本 | Guard 触发 | 纠正错误 | 引入错误 |
|---|---:|---:|---:|---:|
| 冻结公共路径消融 | 16 | 4 | 4 | 0 |
| 独立正式回归 | 80 | 0 | 0 | 0 |

联合证据表明：

1. 当 V8 出现明确目标类型冲突时，Guard 可以选择正确 Core 路径并纠正答案。
2. 当 V8 答案目标类型合法时，即使答案相对 gold 不完美，Guard 也不会越权改写。
3. 对 Core 未覆盖的 V8 扩展能力，Guard 保持旁路。

## 6. 论文可用表述

> 在 16 道公共路径开发消融题上，Core Route Guard 将 Exact/F1 从 75% 提升至 100%，纠正 4 个目标类型路由错误且未引入错误。进一步在与开发集零重叠的 80 道正式分层回归题上，Guard 实现 100% 答案保持率和 0% 错误引入率，表明其能够以保守方式增强真实产业 KGQA，而不干扰 Core 未覆盖能力。

## 7. 限制

- 独立 80 题中没有出现新的明确目标类型冲突，因此没有提供新的纠错成功样本。
- Guard 不能解决实体别名规范化、漏答、多答或 gold 标注差异。
- 当前 Core 仅覆盖四条公共路径，不能代表完整生产 V8。
